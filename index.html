1 · GitHub-Verbindung

prices.csv / transactions.csv / stammdaten.csv leben nur im Repo
Personal Access Token mit Contents: Read and write auf dieses Repo (Fine-grained PAT unter github.com → Settings → Developer settings → Personal access tokens). Sobald verbunden, wird jede Änderung sofort auf GitHub gespeichert — Uploads, Stammdaten-Bearbeitung, alles. Es gibt keinen separaten Zwischenstand mehr, der manuell gesichert werden müsste.
Pfade im Repo: data/prices.csv, data/transactions.csv, data/stammdaten.csv — werden beim ersten Speichern automatisch angelegt.
Bei aktivierter Checkbox liegt das Token im localStorage dieses Browsers (unverschlüsselt) und wird beim Öffnen automatisch wieder eingefüllt und sofort der letzte GitHub-Stand geladen — kein manueller Klick nötig. Nur auf einem eigenen, vertrauenswürdigen Gerät aktivieren.

2 · Splint-Exporte hochladen

Nur diese zwei Buttons betreffen die Original-Dateien von Splint
Diese Uploads ergänzen prices.csv, transactions.csv und stammdaten.csv um neue Zeilen — bestehende Zeilen werden nie überschrieben oder gelöscht (Kurspunkte werden pro Asset/Monat aktualisiert, Transaktionen per eindeutiger ID dedupliziert). Ist GitHub verbunden, wird direkt danach automatisch gespeichert.
AInvestment Opportunities Export
Aktuelle Positionen mit heutigem Kurs. Wird als ein Kurspunkt pro Monat in prices.csv ergänzt/aktualisiert (letzter Upload pro Monat überschreibt nur den Monatswert, nie andere Monate).
BActivities Export
Vollständiges Transaktionsprotokoll von Splint. Neue Transaktions-IDs werden ergänzt, bestehende nicht dupliziert oder verändert.

3 · Erweitert / Fallback

Nur nötig ohne GitHub-Verbindung
prices.csv laden
transactions.csv laden
Stammdaten (Name, Kategorie, Subkategorie, Notizen) gibt es nur als Export/GitHub-Stand — kein manueller Upload, da es dafür keine externe Quelldatei gibt. Bearbeitung erfolgt direkt im Tab «Wertschriften».
